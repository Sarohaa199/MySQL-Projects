# End-to-End Sales and Customer Analytics on Chinook Database Using MySQL

## Project Overview
This repository demonstrates comprehensive SQL-based data analysis using the Chinook sample database. It highlights foundational and intermediate-level query writing and business insights extraction relevant to sales and customer analytics.

## Completed Projects

### Project 1: Customer and Sales Insights
- Total customer count analysis  
- Identification of top billing countries  
- Ranking of top customers by total revenue  
- Evaluation of sales support agents by revenue generation  
- Analysis of customer purchasing frequency

### Project 2: Revenue and Invoice Trends
- Monthly total revenue aggregation  
- Calculation of average invoice value per month  
- Revenue trend analysis over time

## Technologies & Tools
- MySQL (query writing, data extraction)  
- Chinook Sample Database (relational data model)

## How to Use This Repository
1. Import the Chinook database schema and data into your MySQL server or preferred SQL client.  
2. Execute the SQL scripts provided in this repository sequentially to reproduce the analysis.  
3. Review query results to gain insights into sales performance and customer behavior.

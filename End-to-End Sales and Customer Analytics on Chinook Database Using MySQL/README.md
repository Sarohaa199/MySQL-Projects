# Chinook SQL Projects

## Overview
This repository contains SQL projects using the Chinook sample database to showcase foundational and intermediate data analysis skills.

## Completed Projects

### Project 1: Basic Customer and Sales Queries
- Counting total customers
- Top billing countries
- Top customers by revenue
- Employees generating highest revenue
- Customers with multiple invoices

### Project 2: Monthly Revenue Analysis
- Total revenue generated each month
- Average invoice total per month
- Revenue trend over time

## Work in Progress
- Advanced analytics projects combining SQL with Python and Power BI will be added soon.

## How to Use
- Load the Chinook database in MySQL or any SQL client.
- Execute the `.sql` files sequentially.

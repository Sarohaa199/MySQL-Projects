# Library Management System – MySQL Project

## 📘 Project Overview

The **Library Management System** is a SQL-based backend system that manages the core operations of a library, such as tracking books, members, and transactions. This project demonstrates proficiency in relational database design, writing complex SQL queries, and organizing structured data for operational use.

## 🧰 Technologies Used

- **Database**: MySQL
- **Language**: SQL (Structured Query Language)
- **Tools**: MySQL Workbench, VS Code, GitHub

## 🗂️ Database Structure

The schema consists of the following core entities:

- **Books** – Stores information about available books.
- **Members** – Tracks user/member details.
- **Transactions** – Manages book issuances and returns.

> **📌 Future Add-on:** An **Entity-Relationship (ER) Diagram** will be included to provide a clear visualization of table relationships.

## 🚀 Features

- 📚 **Book Management** – Add, update, or delete books.
- 👥 **Member Management** – Register, update, or remove members.
- 🔄 **Transaction Management** – Issue and return books with date tracking.
- 📊 **Reporting** – Identify overdue books and calculate fines.
- 🧾 **Query Logic** – Efficient use of joins, aggregations, and conditional logic to derive insights.
